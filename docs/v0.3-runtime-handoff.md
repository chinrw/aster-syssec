## Runtime smoke

The full TCG rerun completed with:

```sh
make run_kernel \
  AUTO_TEST=syssec \
  SYSSEC_CASE=io/file_io/partial_efault_json \
  TARGET_ARCH=x86_64 \
  ENABLE_KVM=0 \
  QEMU_HOSTFWD=off
```

The guest emitted:

```json
{"case_id":"pipe-partial-efault-read","exit_kind":"normal","return":-1,"errno":14,"first_byte":65,"remaining_return":2,"remaining_errno":0,"remaining_byte_0":65,"remaining_byte_1":66}
```

The CRLF-tolerant marker postcondition exited zero. This result is a positive
contract baseline, not a Linux differential result or a finding.

## Unfinished Runtime Foundation

No runtime adapter exists in aster-syssec. The next core task still needs:

- runtime target, result, guest protocol, oracle image, comparison, and request
  schemas;
- strict marker-delimited JSON parsing and negative fixtures;
- QEMU process management and distinct startup, boot timeout, panic, hang,
  test timeout, invalid protocol, and normal outcomes;
- export and SHA-256 of the exact initramfs static binary;
- pinned Linux kernel, config, rootfs, QEMU, machine, CPU, memory, and SMP;
- a case-specific partial-EFAULT comparison relation;
- mismatch import as `candidate`, never automatic finding promotion.

Do not add fault injection, deterministic race triggers, executable security
reproducers, or finding promotion in this task.

## Unfinished Model and Lab work

Specula still lacks phase-specific execution, hash-bound gates, result import,
and trace consumers. Imported counterexamples must remain candidates.

Fault plans, pause points, counterexample-to-runtime requests, guest sequence
fuzzing, security impact classification, and finding promotion remain outside
the core repository's default context. They belong in an authorization-gated,
VM-only lab after Runtime Foundation and Specula gates are stable.
